# 商务大数据分析课程竞赛 —— 在线评分系统

Flask + SQLite 实现的课程竞赛在线评分系统：学生提交预测结果 CSV 自动评分、排行榜实时更新，管理员可维护赛题、数据文件、评价指标与成绩导出。

## 功能

- **用户管理**：学生账号来自 `学生名单.xlsx`（账号 = 初始密码 = 学号）；内置管理员 `admin / admin888`
- **提交与评分**：上传预测结果 CSV（+ 可选代码压缩包），按管理员启用的评价指标自动计分
- **评价指标**：内置回归 / 分类 / 聚类多算法（见 `metrics_lib.py`），可随时切换并一键重算历史成绩
- **排名与导出**：按历史最佳值排名，支持导出 Excel、打包下载全部提交
- **赛题与数据**：管理员后台维护赛题说明、训练/测试/提交样例/标准答案文件
- **截止控制**：可设置提交截止时间，到期自动关闭提交

## 本地运行

```bash
pip install -r requirements.txt
python app.py
# 浏览器打开 http://127.0.0.1:5000
```

首次启动会自动建库 `scoring.db`、创建管理员账号 `admin / admin888`；
若项目根目录存在 `学生名单.xlsx`（表头：学号、姓名、性别、班级），会自动导入学生（账号 = 初始密码 = 学号）。
Windows 下也可直接双击 `启动评分系统.bat`。

### 需要自备的两个文件（未随仓库提交）

| 文件 | 放置位置 | 用途 |
| --- | --- | --- |
| 学生名单 Excel | 项目根目录 `工业24级名单.xlsx` | 初始化学生账号；也可在后台「用户管理」手动/批量导入 |
| 评分标准答案 CSV | `data/` 目录 | 第 1 列样本 id、第 2 列真实值；在后台「赛题与数据」里指定文件名 |

> 这两个文件含学生个人信息和评分答案，已加入 `.gitignore`，不会提交到仓库。

## 部署（Render / Railway 等）

- 启动命令：`gunicorn app:app`（已提供 `Procfile`）
- 必设环境变量：`SECRET_KEY`（会话签名密钥，务必自定义）
- 可选环境变量：`PORT`（默认 5000）、`FLASK_DEBUG`（设为 `0` 关闭调试）

> ⚠️ SQLite + 本地磁盘存储在多数 PaaS 上不是持久化存储，重启/重新部署后 `scoring.db` 与 `uploads/` 可能丢失。
> 长期运行请挂载持久卷或改用外部数据库 / 对象存储。

## 目录说明

| 路径 | 说明 |
| --- | --- |
| `app.py` | 主程序：路由、评分、后台管理 |
| `metrics_lib.py` | 评价指标算法库 |
| `templates/` `static/` | 前端模板与样式 |
| `data/` | 赛题数据文件（训练 / 测试 / 提交样例 / 标准答案） |
| `uploads/` | 学生上传的结果与代码文件（运行数据，不入库） |
| `scoring.db` | SQLite 数据库（运行数据，不入库） |
